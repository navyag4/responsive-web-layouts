# Responsive Web Layouts

## About the Project

This project contains responsive web layouts
created using HTML and CSS.

It includes a sidebar layout, a product card
using the CSS box model, and a three-column
blog layout using Flexbox.

The website is designed to work on both
desktop and mobile screens.

## Technologies Used

- HTML
- CSS
- Flexbox
- Media Queries

## Features

- Responsive sidebar
- Product card
- Three-column blog layout
- Mobile-friendly design
